      BioEnzyme Activity Lab
      

        
Saturation kinetics on substrate; denaturation is permanent once it happens.

        
Generate one single, complete HTML file for an Enzyme Activity Lab. Students investigate how temperature, pH and substrate concentration affect the rate of an enzyme-catalyzed reaction. Provide sliders for temperature (0 to 80 degrees Celsius), pH (1 to 14) and substrate concentration (0 to 100 percent). Put all the necessary math and rules into one section. Report reaction rate as a percentage of the maximum possible rate, calculated as the product of three factors: a temperature factor peaking at 37 degrees Celsius and falling off on both sides, a pH factor peaking at pH 7 and falling off on both sides, and a substrate factor that follows saturation kinetics, rate proportional to S divided by (25 + S), so the curve rises steeply then flattens. Track the highest temperature the enzyme has been exposed to since the last reset: once that has ever exceeded 60 degrees Celsius the rate is permanently zero regardless of the other sliders, and a Reset enzyme button is the only way back. The layout must include a visible drawing area (a canvas) showing an animated enzyme and substrate, plus a live graph of reaction rate against the variable currently being changed. Include a button to log each trial into a data table and a button to download it as a CSV file. Use a clean, modern design for all styling, and make sure it works on a phone or tablet.

      

    


    

      ChemTitration Curve Builder
      

        
One charge-balance solve, checked against known pH values.

        
Generate one single, complete HTML file for a Titration Curve Builder. Students titrate 25.00 mL of an acid with 0.100 molar sodium hydroxide, using phenolphthalein as the indicator. Let the user select the acid from a dropdown of hydrochloric acid (strong), acetic acid (Ka = 1.8 times 10 to the minus 5) and benzoic acid (Ka = 6.3 times 10 to the minus 5), set its starting concentration from 0.01 to 1.00 molar, and add titrant in adjustable increments by clicking a burette. Put all the necessary math and rules into one section. Do not use separate formulas for the different regions of the curve. Instead solve the charge balance numerically at every point, [Na+] + [H+] = [A-] + [OH-], with [A-] = Ca times Ka divided by (Ka + [H+]), using bisection on [H+], so the buffer region, the equivalence point and the excess-base region all fall out of one equation. Check your work against these values for 0.100 molar acid: acetic acid should read pH 2.88 at the start, 4.75 at half equivalence and 8.72 at equivalence; hydrochloric acid should read exactly 7.00 at equivalence. The layout must include a visible drawing area (a canvas) showing the burette and flask, with the solution turning pink above pH 8.2, and a live graph of pH against volume of titrant added that draws point by point. Include a button to log each trial into a data table and a button to download it as a CSV file. Use a clean, modern design for all styling, and make sure it works on a phone or tablet.

      

    


    

      PhysicsProjectile Motion with Drag
      

        
Drag on, and mass changes the optimum angle. That argument is the lesson.

        
Generate one single, complete HTML file for a Projectile Motion Lab. Students launch a projectile and investigate what launch angle maximizes range. Provide sliders for launch angle (0 to 90 degrees), initial speed (1 to 60 meters per second) and projectile mass (0.1 to 10 kilograms), plus a checkbox to turn air resistance on and off. Put all the necessary math and rules into one section. Launch from ground level with gravity 9.81 meters per second squared. With air resistance off, use the standard projectile equations. With it on, integrate the motion numerically with a quadratic drag force of magnitude k times speed squared, opposing the velocity, where k = 0.5 times air density 1.225 times drag coefficient 0.47 times the cross-sectional area of a sphere of radius 0.05 meters, and divide the drag force by the mass to get the acceleration. This makes mass matter only when drag is on, which is the point of the lab: at 30 meters per second a 0.1 kilogram projectile should peak in the high 30s of degrees and a 10 kilogram one near 45 degrees. Display the optimum angle found so far. The layout must include a visible drawing area (a canvas) that animates the flight path and leaves a trace of previous shots for comparison, plus a live readout of maximum height, time of flight and range. Include a button to log each shot into a data table and a button to download it as a CSV file. Use a clean, modern design for all styling, and make sure it works on a phone or tablet.

      

    


    

      EarthEarthquake Epicenter Triangulation
      

        
Map scale and station positions pinned so the circles actually intersect.

        
Generate one single, complete HTML file for an Earthquake Epicenter Locator. The program should show a square map 600 kilometers on each side with a visible scale bar, place three seismograph stations at fixed points on it (100, 100), (500, 150) and (300, 500) in kilometers, and secretly place an earthquake epicenter at a random point at least 50 kilometers inside the edges of the map. For each station, draw a seismogram with a labeled time axis in seconds and clearly marked P-wave and S-wave arrivals. Put all the necessary math and rules into one section, using a P-wave speed of 6.1 kilometers per second and an S-wave speed of 3.5 kilometers per second, so that distance in kilometers equals the P-S lag in seconds divided by (1/3.5 - 1/6.1), which is about 8.21 kilometers per second of lag. Students read the lag off each seismogram, type it into an input box, and the program draws a circle of the corresponding radius around that station, drawn to the same scale as the map so the three circles intersect at the epicenter. The layout must include a visible drawing area (a canvas) showing the map, the stations and the circles as they are drawn. Include a button labeled 'Check my epicenter' that reveals the true location and the student's error in kilometers. Use a clean, modern design for all styling, and make sure it works on a phone or tablet.

      

    


    

      Phys SciDensity Column
      

        
Named liquids and densities, so the layers mean something.

        
Generate one single, complete HTML file for a Density Column Lab. The program shows a graduated cylinder holding four liquid layers, labeled, from the bottom up: corn syrup at 1.38, water at 1.00, vegetable oil at 0.92 and lamp oil at 0.78 grams per cubic centimeter. Students build an object by setting its mass (10 to 500 grams) and its volume (10 to 500 cubic centimeters) with sliders, then drop it into the column and watch it settle. Put all the necessary math and rules into one section: calculate density as mass divided by volume, display it to two decimal places, and rest the object on top of the first layer that is denser than it is. An object denser than 1.38 sinks to the bottom, and one less dense than 0.78 floats on the surface. Start with default values that put the object in the middle of the column. The layout must include a visible drawing area (a canvas) that animates the object sinking or floating to its resting layer. Include a challenge mode that names a target layer and asks the student to build an object that will float there. Include a button to log each attempt into a data table and a button to download it as a CSV file. Use a clean, modern design for all styling, and make sure it works on a phone or tablet.
